# Segurança

A versão 0.1.0 ainda está em preparação. Não há release pública nem canal de
segurança por e-mail definido neste repositório.

Se o repositório no GitHub oferecer **Security → Report a vulnerability**, use
esse canal privado para relatar vulnerabilidades. Caso a opção não esteja
habilitada, abra uma issue solicitando um canal privado, sem publicar dados
pessoais, credenciais, arquivos maliciosos ou detalhes de exploração.
O mantenedor precisa habilitar o recebimento privado antes da release pública.

No relato privado, informe a versão, o sistema operacional, o comportamento
esperado/observado e passos mínimos de reprodução com dados fictícios.
Não envie exportações reais do Instagram.

O escopo inclui leitura de ZIP/JSON, gravação de resultados, empacotamento e
exposição acidental de dados. Análise de relações é local; abrir um perfil no
navegador é uma ação explícita do usuário. A aplicação não valida a atividade
ou a identidade de perfis na rede.
